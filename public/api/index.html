Fertility Tracker API

Fertility, births, deaths, net migration, migrant stocks, UN projections to 2100 and a population-decline risk score for every country. Static files: no key, no sign-up, CORS open, refreshed every Monday.

JSONCSVOpenAPI 3.1JSON Schemallms.txt

Base URL

https://fertility-tracker-live.vercel.app/api/v1/

Every API file is served with Access-Control-Allow-Origin: *, so browsers, servers and AI agents can fetch it directly. Codes are ISO 3166-1 alpha-3 (WLD = world, XKX = Kosovo). Numbers are numbers, missing values are null, and every record includes iso3, name and region.

Endpoints

FileWhat it contains
index.jsonManifest: exact source URLs, data vintages, endpoints, known data gaps, generatedAt and contentHash. Both change only when a number changes.
countries.jsonSummary for every country plus the world: population, fertility, median age, 65+ share, latest births, deaths and net migration (absolute and per 1,000), immigrant and emigrant stock, UN 2050/2100 projection, generation ratio, risk score, tier, rank and reasons.
countries/{ISO3}.jsonEverything for one country: yearly series 1950-2100 (estimates, then the UN medium projection), migrant stock history, top 10 countries immigrants come from and emigrants live in, full risk breakdown.
risk.jsonCountries ranked by population-decline risk (1 = highest), with component points, inputs, reasons and the methodology.
countries.csvOne row per country; nested fields flattened (components_births, projection_change2100Pct, …).
timeseries.csvLong format iso3,year,variant,metric,value, about 11 MB.
status.jsonWhen the weekly refresh last ran and whether it succeeded.
openapi.jsonOpenAPI 3.1. JSON Schemas with field descriptions: countries, country, risk, index, status.

Try it

# The 10 countries at highest risk of population decline
curl -s https://fertility-tracker-live.vercel.app/api/v1/risk.json \
  | jq -r '.ranking[:10][] | "\(.rank). \(.name)  \(.score) \(.tier)"'

# Japan in 2050 (UN projection): births, deaths, net migration
curl -s https://fertility-tracker-live.vercel.app/api/v1/countries/JPN.json \
  | jq '.series[] | select(.year == 2050) | {births, deaths, netMigration}'
const base = "https://fertility-tracker-live.vercel.app/api/v1/";
const { countries } = await (await fetch(base + "countries.json")).json();
const korea = countries.find((c) => c.iso3 === "KOR");
console.log(korea.tfr.value, korea.risk.tier, korea.risk.factors[0]);

Key fields

FieldMeaning
tfrFertility rate: births per woman. 2.1 keeps each generation the same size.
{value, year, source}Headline figures take the newest year across sources. source is WB (World Bank), UN-WPP or UN-DESA.
componentsLatest UN estimate year: population change = births − deaths + net migration, also per 1,000 people. migrationOffsetPct: how much of the natural decline immigration replaces.
migrantStockimmigrants: people living here who were born abroad (inflow). emigrants: people born here who live abroad (outflow). emigrantsPct divides by today's residents (UN definition); livingAbroadPct is the share of everyone born in the country who lives abroad. No global source publishes gross yearly inflows and outflows, so use netMigration for the yearly flow.
projectionUN WPP 2024 medium variant: population in 2050 and 2100, % change from basePopulation in baseYear (latest UN estimate, 2023), peak year, the year the population halves, when deaths overtake births.
generationsratio = tfr / 2.1: each ~30-year generation is this share of the last. At 1.14, 100 people → 54 → 29 → 16 → 9.
riskScore 0-100 with tiers Critical (≥ 70), High (≥ 55), Elevated (≥ 40), Moderate (≥ 20) and Low, a rank (1 = highest) and plain-English reasons.

How the risk score works

Five parts, each scaled from 0 (no risk) to 1 (maximum), weighted and added up to 100:

WeightPartFrom 0 → 1
35Fertility below replacementfertility 2.1 → 0.8
30UN-projected decline2050: 0% → −25% (weight 1); 2100: 0% → −60% (weight 2)
15More deaths than births+5 → −7 per 1,000 people
10Aging65+ share 7% → 30%; median age 25 → 50
10Migration not filling the gapshare of the natural decline not covered by net immigration

Places under 100,000 people are scored but not ranked. Full method: METHODOLOGY.md. Field reference: API.md.
